# Security Policy for Pulse Music

**Pulse Music Studio** prioritizes the security and privacy of all users. All releases are signed with authentic cryptographic release keys and protected against tampering.

---

## Supported Versions

Security updates and patches are actively provided for current and recent major releases:

| Version | Supported | Notes |
| :--- | :--- | :--- |
| `3.2.x` | :white_check_mark: | Current active release branch (`v3.2.9`) |
| `3.1.x` | :warning: | Maintenance / critical fixes only |
| `< 3.1` | :x: | Unsupported; please update to latest |

---

## Reporting a Vulnerability

If you discover a security vulnerability or security bug in Pulse Music, please disclose it responsibly:

1. **Email Directly**: Contact the sole project owner and lead developer **Muthumanikandan B**:  
   📧 `muthumanikandanb2005@gmail.com`
2. **Include Details**:
   - App version affected (e.g. `v3.2.9`)
   - Platform (Android version or Windows version)
   - Step-by-step reproduction instructions or proof of concept
   - Expected vs observed behavior
3. **Response Timeline**:
   - Initial acknowledgement within **24 hours**.
   - Remediation and advisory timeline coordinated within **7 days**.
   - A critical security patch and OTA update will be broadcast immediately upon validation.

---

## Security Guarantees

- **Zero Tracking**: Pulse Music does not track users, sell data, or collect telemetry.
- **Direct GitHub CDN OTA**: All OTA updates originate directly from authentic signed GitHub releases.
- **Verified Package ID**: `com.pulse.music`
